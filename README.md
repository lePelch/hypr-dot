# Nouvelle configuration

Chaque écrans garde la même configuration de workspaces.

- Écrans 1 : Possède les workspaces [1, 2, 3]
- Écrans 2 : Possède les workspaces [4, 5, 6, 0]
- Écrans 3 : Possède les workspaces [7, 8, 9]

# Workspaces Store

- Il est possible de mettre dans le configuration store des workspaces.
- Les insertion dans le workspaces store sont toujour insérer à la fin.
- Il est possible de les sortir en faisant **SUPER + CTRL + NUMBER**.
- La numérotation commence à 0.
- Les insertion se font avec **SUPER + A**.
- Les pop se font avec **SUPER + D**.
- Les workspaces vides ne peuvent être insérer.
